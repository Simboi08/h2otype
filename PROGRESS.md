## Scope and known limitations
- Sprint generates 600 words per run for common-word sets; original sentences still use a long repeating passage. Unusually fast early completion is shown as a result but excluded from records. Duration defaults to 15 after reload; best scores persist per pool/duration/browser/origin.
- Zen generates common-word batches or uses the original cycling sentence collection. Only recent history remains editable; older characters are finalized into totals. The local XP/draft profile is intended for one active tab (last save wins); each edit saves text/XP atomically, while a hard crash can lose up to five seconds of active elapsed time. No cloud sync or multi-tab conflict handling.
- All MVP preference toggles and capped combo bonuses are implemented. No unlockable cosmetics, accounts, or XP cloud sync; progression stays local. Shared Daily guest rankings require the optional deployment/database configuration.
- Input is end-editing only; click/arrow selection cannot edit the middle of a session. Native text input is intentionally visible beneath the character-feedback passage for predictable keyboard/mobile behavior.
- Only Chromium automation has run. Real mobile keyboards, Safari, Firefox, screen-reader usability, and platform-specific IME behavior need broader testing; simulated composition and native input events pass here.
- Dependencies/lockfile remain from Milestone 0. This cloud machine uses the writable npm cache documented in README and preinstalled `/usr/bin/chromium`; Playwright's browser-download host was blocked during setup.
